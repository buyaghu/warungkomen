# Paket akun Instagram — Warung Komen

Semua yang dibutuhkan untuk membuat dan mengisi akun. Tinggal salin-tempel.

## 1. Username (cek ketersediaan saat daftar, urut prioritas)

1. `warungkomen` (sudah dipilih)
2. `warung.komen`
3. `warungkomen.id`
4. `masjuned.warung`

Pakai username yang sama di TikTok, YouTube Shorts dan Facebook kalau tersedia.

## 2. Nama (kolom "Nama", ikut terbaca di pencarian)

```
Warung Komen | Menu dari Komen
```

## 3. Bio (maksimal 150 karakter)

```
🍜 Warung yang menunya diatur netizen
🧾 Follow = jadi pelanggan
🍳 Komen teratas = dimasak besok
👨‍🍳 Mang Juned, owner (kena PHK)
```

Cadangan yang lebih pendek:

```
Warung kecil, menunya kalian yang tentukan.
Follow = pelanggan · Komen = pesan menu 🍳
Cabang 1/100 👇
```

## 4. Kategori dan jenis akun

- Jenis akun: **Kreator** (Settings → Account type and tools → Switch to professional → Creator)
- Kategori: **Kreator digital** (atau "Hiburan")
- Tampilkan kategori di profil: **ya**

## 5. Foto profil

`Avatar.png` (1080×1080). Mang Juned di depan latar sinar, dengan papan WARUNG KOMEN.

## 6. Highlight (buat setelah ada story)

| Nama highlight | Cover | Isi story |
|---|---|---|
| Daftar Menu | `CoverMenu.png` | Menu yang sudah dimasak + screenshot komen pemenangnya |
| Aturan Main | `CoverAturan.png` | 3 aturan: follow = pelanggan, komen = pesan menu, komen teratas = dimasak besok |
| Buku Bon | `CoverBon.png` | Nama-nama pengomentar terlucu ("yang ngutang di warung") |
| Rapat Pelanggan | `CoverRapat.png` | Polling story untuk memilih 2 komen teratas |
| Perjalanan | `CoverWarung.png` | Naik level warung: gerobak → tenda → warung → ruko → restoran |

## 7. Postingan pertama: Reel Day 1

Video: `day1-reel.mp4`

Caption:

```
Day 1 🍜 Warung ini menunya diatur kalian.

Mang Juned baru kena PHK, modalnya cuma satu gerobak bekas.
Pelanggan: 0. Omzet: 0. Menu: belum ada.

🧾 Follow = jadi pelanggan
🍳 Komen = pesan menu
❤️ Komen teratas, besok dimasak

Mau warung ini jualan apa? Tulis di komen 👇

#warungkomen #day1 #animasi #ideusaha #kulinerindonesia #fyp
```

Cover Reel: ambil frame stempel "KOMEN = PESAN MENU" (detik ±38). Tulisannya paling jelas dan memancing rasa penasaran.

Komentar pertama dari akun sendiri (lalu pin):

```
📌 Aturan: komen dengan like terbanyak sampai besok jam 17.00 yang dimasak di Day 2. Satu orang boleh komen lebih dari sekali 😄
```

## 8. Checklist setelah posting

- [ ] Pin komentar aturan di atas
- [ ] Balas 10–20 komen pertama (balasan memancing komen baru)
- [ ] Story: repost Reel + polling "Mau jualan apa?" dengan 2 komen teratas
- [ ] Masukkan story aturan ke highlight "Aturan Main"
- [ ] Jadwal tetap: posting tiap hari di jam yang sama (saran: 19.00 WIB)
- [ ] Screenshot komen pemenang sebelum jam 17.00 besok, untuk bahan Day 2

## 9. Yang jangan dilakukan

- Jangan memakai nama, logo atau karakter akun lain (misalnya Kampung Komen). Format "dibangun dari komen" boleh, identitasnya harus milik sendiri.
- Jangan membeli follower: angka "PELANGGAN" di video harus jujur, itu bagian dari ceritanya.
