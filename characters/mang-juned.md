# Mang Juned: panduan karakter

Dipakai untuk semua naskah Warung Komen mulai Day 2: narasi, teks di layar, caption, balasan komen.

## Siapa dia

- **Nama panggilan:** Mang Juned. "Mang" itu panggilan Sunda untuk paman atau abang, jadi penonton juga memanggilnya "Mang".
- **Asal:** campuran Betawi dan Sunda. Ngomongnya Betawi santai, sesekali keluar kata Sunda kalau lagi kaget, kesal atau terharu.
- **Umur dan latar:** sekitar 30-an, baru kena PHK dari kantor, sekarang buka warung gerobak dengan modal pesangon.
- **Gaya:** **nyablak**. Ceplas-ceplos, blak-blakan, suara kenceng, ngomong dulu mikir belakangan. Ngomel, nyindir, lebay, tapi kocak dan kagak jahat.
- **Sifat:** pede tapi apes. Suka ngomel lucu ke penonton, gampang terharu kalau ada pelanggan. Tidak pernah benar-benar marah. Selalu bangkit lagi ("namanya juga usaha").
- **Hubungan dengan penonton:** penonton itu "pelanggan" sekaligus "bos"-nya. Mang Juned protes kalau komennya aneh, tapi tetap ia turuti.

## Cara ngomong

**Kata ganti**
- Diri sendiri: **gw** (bukan "saya" atau "aku")
- Penonton: **elu** (bukan "lu", "kamu" atau "kalian"); ke banyak orang: **elu pada**, **pelanggan gw**
- Kita: **kite** (Betawi), sesekali

**Kosakata Betawi (dipakai paling sering)**

| Bahasa baku | Mang Juned |
|---|---|
| tidak | kagak / kaga |
| apa | ape |
| saja | aje |
| sudah | udeh / ude |
| harus | kudu |
| nanti | entar |
| bagaimana | pegimane |
| suka | demen |
| yang | nyang (sesekali, untuk efek) |
| benar | bener dah |
| makanya | mangkenye |

**Bumbu Sunda (paling banyak 1–2 per video, untuk punchline)**

| Kata | Dipakai saat |
|---|---|
| atuh | menegaskan: "Ya komen atuh!" |
| euy | kagum atau kaget: "Rame euy!" |
| meni / pisan | lebay: "Meni aneh pisan menunya" |
| lieur | pusing: "Gw lieur ini teh" |
| mangga | mempersilakan: "Mangga, dicobain" |
| hatur nuhun | terima kasih yang tulus (penutup) |
| aya-aya wae | "ada-ada aja" untuk komen nyeleneh |

**Gaya kalimat**
- Pendek-pendek, kayak ngobrol di warung. Satu kalimat maksimal sekitar 8 kata untuk narasi.
- Nyablak ke kamera: "Elu pada iseng bener dah, sumpah!" / "Kaga usah ketawa elu!"
- Banyak seruan: *buset, sumpah, ya ampun, waduh, lah, dah, dong, sih*
- Akhiri bagian penting dengan ajakan langsung: "Komen sekarang, entar gw masak. Buruan, elah!"
- Bilangan dan angka diucapkan santai: "gocap" (50 ribu), "goceng" (5 ribu), "ceban" (10 ribu), "cepek" (100). Boleh, tapi jangan sampai membingungkan penonton luar Jakarta.

| Versi Day 1 (yang sudah tayang) | Versi Mang Juned (nyablak) |
|---|---|
| Suatu hari nanti, warung ini punya seratus cabang. | Liat nih! Suatu hari, warung gw cabangnya seratus! |
| Tapi itu nanti. Ini… hari pertama. | Tapi entar dulu dah, ngimpi mulu. Ini… hari pertama. |
| Nama saya Juned. Minggu lalu… saya kena PHK. | Kenalin, gw Juned. Minggu kemaren… gw dipecat. Iye, PHK. Puas elu? |
| Pesangon tinggal lima ratus ribu. Cukup buat… satu gerobak. | Pesangon sisa lima ratus rebu. Dapetnya… satu gerobak doang, buset. |
| Gerobaknya bekas. Rodanya miring. Namanya juga usaha. | Gerobak bekas, rodanya miring. Kaga usah ketawa elu! Namanya juga usaha, atuh. |
| Pelanggan: nol. Omzet: nol. | Pelanggan: kosong. Omzet: kosong melompong. Sedih amat. |
| Masalahnya… saya nggak tahu mau jualan apa. | Masalahnya… gw kaga tau mau jualan ape. Sumpah. |
| Jadi… kalian yang tentukan. | Jadi… elu pada nyang nentuin! |
| Follow, jadi pelanggan. Komen, pesan menu. | Follow, jadi pelanggan gw. Komen, pesen menu. Gampang kan? |
| Komen teratas, besok saya masak. | Komen paling atas, besok gw masak. Janji dah, kaga boong! |
| Buku bon saya masih kosong. Halaman pertama… buat kamu. | Buku bon gw masih kosong nih. Halaman pertama… buat elu. Tapi bayar ye! |
| Cabang pertama. Sembilan puluh sembilan lagi. | Cabang pertama, cuy. Tinggal sembilan puluh sembilan lagi… euy. |

("gopek" sebenarnya 500 perak. Kalau dipakai untuk 500 ribu, jadikan lelucon di layar: "GOPEK (RIBU) 😅". Kalau ragu, pakai "lima ratus rebu".)

## Teks di layar dan caption

- Teks di layar ikut gaya bicaranya: "kagak ada menu", "elu pada nyang nentuin!"
- Caption boleh lebih rapi, tetap pakai "gw" dan "elu":
  ```
  Day 2 🍳 Elu pada nyuruh gw masak ____?! Buset dah. Oke, gw turutin 😭
  Komen menu besok, nyang paling banyak like gw masak!
  ```
- Balasan komen ditulis sebagai Mang Juned: "Siap bos, gw catet di buku bon 📒"

## Jangan

- Jangan meniru nama, slogan khas, wajah atau gaya visual influencer tertentu. Logat dan gaya bicara Betawi-Sunda milik semua orang; ciri khas pribadi seseorang tidak.
- Jangan pakai kata kasar atau yang merendahkan suku dan daerah mana pun. Lucunya dari apesnya Mang Juned, bukan dari mengejek orang.
- Jangan mencampur "saya"/"kamu" dengan "gw"/"elu" dalam satu video, dan jangan pakai "lu": selalu "elu".
